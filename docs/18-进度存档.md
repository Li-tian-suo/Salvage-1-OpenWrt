## 还差什么

### 1. 刷机（需要串口或 SSH）

**最安全**：U-Boot 里 TFTP 加载 initramfs，不写 flash

```
tftpboot 0x44000000 libwrt-qualcommax-ipq807x-hk09_hk09-initramfs-uImage.itb
bootm 0x44000000
```

**要写 flash 的话**（新的 factory.ubi 40 MB，当前 rootfs 只有 22 MiB）：

```
ubi remove rootfs
ubi remove rootfs_data
ubi create rootfs $filesize
ubi write 0x44000000 rootfs $filesize
```

**绝不能碰** `mtd18`（`0:ART`）、`mtd15`（`0:APPSBLENV`）。

### 2. Wi-Fi 实际验证

进去后：

```sh
iw dev | grep -E 'Interface|channel'
ls /lib/firmware/ath11k/IPQ8074/hw2.0/
```

期望：
```
Interface phy0-ap0   channel 36 (5180 MHz), width: 80 MHz
Interface phy1-ap0   channel 1 (2412 MHz), width: 20 MHz

board-2.bin
cal-ahb-c000000.wifi.bin     ← 关键
```

### 3. 「跑 homebox 就 Wi-Fi 去世」的根因

**还没确认**。已排除：内存不足（20 MB/884 MB）、homebox 自身、CPU（load 0.11）。

最可疑：NSS 的 `qcom,wlan-dataplane-offload-enabled`（在
`ipq8074-nss.dtsi` 里，37 个 ipq807x 设备共用，不是我们引入的）。

这版加了看门狗（自动 `wifi reload` / `down-up`）+ pstore（留崩溃现场），
但**要复现一次才能抓到**：

```sh
cat /sys/fs/pstore/*        # 有内容就是抓到了
logread | grep hk09-wifiguard
```
